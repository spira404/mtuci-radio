Элементы
- с сосредоточенными параметрами — у них процессы рассматриваются "в одной точке". Являются таковыми если их размер меньше десятой части волны — $\huge l < \lambda / 10$. Примеры: резисторы, конденсаторы, катушки
- с распределёнными параметрами — у них свойства распределены по всей длине, ток в разных точках элемента неодинаков в один момент времени. $\huge l > \lambda/10$. Примеры: коаксиальный кабель, антенна, волновод.
