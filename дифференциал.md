[[базмат#Производная]] — скорость изменения функции в точке, отношение дифференциалов, насколько быстро функция растёт или убывает. $f'(x) = dy/dx$
Используется для анализа поведения функции на промежутке (возрастание, убывание)

дифференциал — изменение функции, вызванное малым изменением аргумента, т.е. на сколько изменится результат функции $dy = f'(x) dx$
Пример: имеется функция $y(x) = x^2$, тогда при изменении функции на $dx$, результат функции будет $dy = 2x \cdot dx$
Используется для вычислений конкретных значений

Итого: 
- производная показывает скорость изменения функции
- дифференциал показывает значение изменения функции от (обычно мелкого) аргумента
